# 🧮 Advanced Calculator in C

A feature-rich calculator application developed using C.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Power calculation
- Square root
- Factorial
- Trigonometric functions
- Logarithmic functions
- Absolute value
- Even/Odd checking
- Prime number checking
- Calculation history
- File handling

## 🛠️ Technologies

- C Programming
- GCC Compiler
- Math Library
- File Handling

## ▶️ How to Run

Compile the program:

```bash
gcc -Wall calculator.c -o calculator.exe -lm
